  \adminipull{Reading the captions. Finding the claims. Going to look.}

  \vspace{5mm}
  \begin{itemize}
    \item Markers appear on the scrubber as each claim is decided.
    \item Scrub to a red marker: the notice, then the source behind it.
    \item Every link opens a page that contains the quoted line.
  \end{itemize}
  \vspace{4mm}
  \adminicallout[adminilink]{Roughly half the practical score lives in these
    three minutes.}
  \note{%
    Play the prepared video. 1) Click Check facts; while it streams, say ``it is
    reading the captions, pulling out the checkable claims, and going to find
    sources for each one.'' 2) Point at markers appearing on the scrubber.
    3) Scrub to a red marker; let the notice appear and say nothing. 4) Open one
    source link, then: ``That quoted line is on that page. We checked it was,
    before we showed you this.'' If anything stalls, keep talking, scrub to a
    marker already on the bar, and never apologise for the network.%
  }

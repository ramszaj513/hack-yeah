Sterowanie

Jak używać Relay

Relay wpasowuje dary w przejazdy, które i tak się dzieją, i rozdziela pomoc sprawiedliwie — tak, żeby dalekie i pilne punkty nie zostały bez wsparcia.

Mapa

  • szara linia — przejazd (O → D)
  • mała kropka — skrzynka (kolor = kategoria)
  • duże koło — punkt potrzeb (kolor = pilność, rozmiar = braki)
  • pomarańczowa linia — sugerowany objazd

Panel — 3 kroki

  1. Tryb: Fair-share (sprawiedliwy) albo Nearest-fit (baseline „Uber”).
  2. Starvation Index: „stan” vs „po sugestiach” + słupki zapełnienia punktów.
  3. Sugerowane objazdy: kliknij Przejmij, żeby zrealizować dostawę.

Najkrótsze demo

Ustaw Fair-share → zobacz, że daleki punkt „Rembertów-Wschód” (pilność 5) jest obsłużony. Kliknij Reset, ustaw Nearest-fit → ten sam punkt ma 0%, a Starvation Index jest wyższy. To cała różnica.

Sugestie są efemeryczne — nie rezerwują zasobów, dopóki nie klikniesz „Przejmij”. Pierwsze przejęcie wygrywa.

How to use Relay

Relay fits donations into trips that are happening anyway, and distributes aid fairly — so that far-away, urgent points are not left without support.

The map

  • grey line — trip (O → D)
  • small dot — crate (color = category)
  • big circle — need-point (color = urgency, size = unmet)
  • orange line — suggested detour
  • colored line — active detour (claimed/picked up/delivered)

The tabs

  • Demo — mode switch, metrics, suggestions, active detours, checkpoints.
  • Add — report crates, trips and need-points.
  • Manage — edit or delete resources, filter the map.
  • Compare — Fair-share vs Nearest-fit on the same data.

Suggested detours and checkpoints

A suggestion is valid for a limited time (a countdown is shown). Claim it to reserve the crates, then confirm Picked up and Delivered at your pace.

The shortest demo

On the Compare tab, run the comparison: the far-away “Rembertow East” point (urgency 5) is served under Fair-share but starved under Nearest-fit — and the Starvation Index differs. That is the whole difference.
